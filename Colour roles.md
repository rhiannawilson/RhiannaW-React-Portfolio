Here is a **clear, strategic design plan** for using:

* `#000000` (Black)
* `#FFFFFC` (Off-White)
* `#BEB7A4` (Warm Beige)

to build a **calm, elegant, modern portfolio from scratch**:

---

## 🎨 Colour Roles

✅ **#000000 (Black)**
– **Primary Text** (headings, body text)
– **Button text**
– **Borders or minimal dividers**
– **Icons**

✅ **#FFFFFC (Off-White)**
– **Main background** (body)
– **Card backgrounds**
– **Sections for readability**

✅ **#BEB7A4 (Warm Beige)**
– **Accent colour** for:

* Button backgrounds
* Link hover states
* Section dividers
* Small icon fills or borders
* Highlight boxes or pull quotes

---

## ✨ Typography Recommendations

### Headings:

* **Font:** `Cormorant Garamond`, `Playfair Display`, or `EB Garamond` (serif, elegant)
* **Color:** `#000000`
* **Weight:** 600–700

### Body:

* **Font:** `Work Sans`, `Inter`, `Lato`, or `Open Sans` (sans-serif, clean, modern)
* **Color:** `#000000`
* **Weight:** 300–400

---

## 🖼️ Background & Layout

* Entire page: `background-color: #FFFFFC;`
* Use **ample white space** for a calm, breathable layout.
* Use `#BEB7A4` for **thin dividers** between sections for structure without heaviness.

---

## 🖱️ Buttons

* **Primary Button:**

  * `background-color: #BEB7A4;`
  * `color: #000000;`
  * Border radius: 6–8px
  * Padding: 0.75rem 1.5rem
  * Font: Body font, medium weight

* **Hover State:**

  * Slightly darken `#BEB7A4` (e.g., `#a79f8c`)
  * Or invert: `background-color: #000000; color: #FFFFFC;`

---

## 🔗 Links

* **Default:** `color: #000000; text-decoration: none;`
* **On Hover:** `color: #BEB7A4; text-decoration: underline;` for a subtle, elegant highlight.

---

## 🗂️ Cards (Projects/Blog)

* **Background:** `#FFFFFC;`
* **Text:** `#000000;`
* **Border:** `1px solid #BEB7A4;` or a subtle shadow
* **Title hover:** highlight title in `#BEB7A4` on hover

---

## 🩶 Example CSS Structure

```css
body {
  background-color: #FFFFFC;
  color: #000000;
  font-family: 'Work Sans', sans-serif;
}

h1, h2, h3 {
  font-family: 'Cormorant Garamond', serif;
  color: #000000;
}

.button {
  background-color: #BEB7A4;
  color: #000000;
  border: none;
  padding: 0.75rem 1.5rem;
  border-radius: 8px;
  transition: background-color 0.3s ease;
}

.button:hover {
  background-color: #a79f8c;
  color: #000000;
}

a {
  color: #000000;
  text-decoration: none;
}

a:hover {
  color: #BEB7A4;
  text-decoration: underline;
}

.divider {
  border-top: 1px solid #BEB7A4;
  margin: 2rem 0;
}

.card {
  background-color: #FFFFFC;
  border: 1px solid #BEB7A4;
  padding: 1rem;
  border-radius: 8px;
}
```

---

## 🩶 Summary

✅ **Use black for clarity & contrast**
✅ **Off-white for calm, open space**
✅ **Warm beige for modern elegance, consistent highlights**
✅ Pair with **clean serif + sans-serif fonts**
✅ Keep **ample white space** to maintain elegance
✅ Use **hover effects** for liveliness without clutter
